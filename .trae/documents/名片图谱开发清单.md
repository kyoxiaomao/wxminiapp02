## S4 图谱模块（核心：index.html 交互移植）

### 4a. 画布与布局引擎

- [x] **Canvas 2D 同层渲染**，每帧 draw；视口状态 `{ k, center }` 自管（替代 DOM viewBox 方案）
- [x] 力导向 tick 1:1 移植：斥力 12000 / 弹簧（夫妻 96、亲子 158）/ 向心 0.0022 / 代际分层力（GEN_Y 第1代-190、2代10、3代210）/ 阻尼 0.72 / alpha 衰减 0.9825、下限 0.004
- [x] 边交叉避让：线段严格相交判定 + 节点拉向亲属中心（强度 0.06、活动量下限 0.12、最多 900 帧）
- [x] 程序化头像：hash(姓名+id) 选肤/发/衣配色，男女发型差异，Canvas path 绘制 + 圆形裁剪
- [x] 关系标签：连线中点白底圆角 rect + 随线角度翻转保持正读
- 移植参考：[index.html#L480-L577](file:///d:/WXminiapp/miniapp02/index.html#L480-L577)（布局 tick）、[index.html#L240-L337](file:///d:/WXminiapp/miniapp02/index.html#L240-L337)（程序化头像）
- 产出：`src/utils/forceGraph.ts`（引擎，参数与算法 1:1）、`src/utils/avatarPainter.ts`（头像绘制）

### 4b. 手势交互（小程序无 Pointer Events，需用 touch 重写）

- [x] 单指拖空白 = 平移；双指捏合 = 以按下瞬间双指中点对应的世界坐标为锚点缩放（0.22–3 倍，锚点不漂移）
- [x] 拖拽节点 = pin 住跟随手指，松手恢复仿真（alpha 重新升温）
- [x] 点击判定：位移 <6px 算点击——点节点弹详情卡，点空白关闭并取消高亮
- [x] 多指状态用 `touches` 数组自管理（替代 pointerId Map + setPointerCapture）
- [x] 选中高亮：halo + 描边加粗，其余节点/连线透明度降至 0.22
- [x] 启动取景：第 45 帧立即 fitView 保证首屏可见，第 170 帧收敛后平滑重新取景；重置按钮 = 随机微扰重播布局 + 500ms 后平滑 fitView
- 移植参考：[index.html#L684-L807](file:///d:/WXminiapp/miniapp02/index.html#L684-L807)（手势）、[index.html#L632-L681](file:///d:/WXminiapp/miniapp02/index.html#L632-L681)（取景/动画）

## 风险备忘（v0.2 更新）

| 风险 | 对策 |
|---|---|
| 小程序无 Pointer Events | touch 事件自管理多指（S4b） |
| SVG DOM 每帧 setData 性能差 | Canvas 2D 同层渲染，布局算法不变只换绘制层 |
| Mock 数据不持久化 | 重启重置为假数据；上云时仅替换 store 实现（S2 已接口隔离） |
| 假头像非真实图片 | 程序化头像复刻 index.html；真实头像 P1 接上传 |
| iOS 虚拟支付限制 | 会员只做权益展示，付费方案 P1 评估 |
