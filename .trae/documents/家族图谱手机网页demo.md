# 家族图谱手机网页 Demo 实施计划

## Summary

从零创建一个**单文件、零依赖**的家族图谱手机网页 demo：`index.html`（内联全部 CSS/JS），使用原生 SVG 渲染 + 自研轻量力导向布局，复刻参考图（NRD Studio 关系图谱）的核心视觉效果——圆形头像节点（紫色描边）、姓名+称谓标签、连线上带关系标签、可缩放拖拽画布、点击节点弹出详情卡。针对手机触摸交互（单指拖拽、双指捏合缩放）做适配。

## Proposed Changes

### 唯一产出文件：`index.html`（项目根目录）

单文件包含 `<style>` + `<script>`，不引用任何外部 CDN/图片/字体，双击即可在桌面或手机浏览器运行。

#### 1. 数据模型（JS 顶部常量区，便于替换）

```js
const NODES = [
  { id: 'p1', name: '陈鸿儒', role: '族长', gen: 1, gender: 'm' },
  { id: 'p2', name: '林淑芬', role: '夫人', gen: 1, gender: 'f' },
  // ... 约 12-14 人，三代虚构家族
];
const LINKS = [
  { source: 'p1', target: 'p2', type: 'spouse', label: '夫妻' },
  { source: 'p1', target: 'c1', type: 'parent', label: '长子' },
  { source: 'c1', target: 'c2', type: 'sibling', label: '兄妹' },
  // ...
];
```

- `type` 三种：`spouse`（夫妻，实线加粗）、`parent`（亲子，标签如"长子/次女"）、`sibling`（兄弟姐妹，虚线、标签如"兄妹/姐弟"）
- `gen` 仅用于布局初始 y 坐标预置，加速收敛，不参与最终视觉
- 规模控制在 ~14 节点，自研 O(n²) 斥力计算无性能压力

#### 2. SVG 渲染层

- 全屏 `<svg id="scene">`，`viewBox` 动态管理实现缩放/平移；背景 `#d9c9dd`（参考图淡紫粉）
- 节点 `<g class="node">`：`<circle r="26">`（填充程序化头像，描边 `#7d3c98` 宽 3px）+ 节点下方两行文字（名字 15px 加粗 / 称谓 11px 灰色，`text-anchor: middle`）
- **程序化头像**（零依赖关键）：根据 `gender` + id 哈希生成简笔画 SVG 头像（脸型 circle + 发型 path + 五官点线），4-6 种发型/配色轮换，贴近参考图效果且无需图片资源
- 连线 `<line>`（或微弧 `<path>`）：夫妻线 `#8e44ad` 宽 2.5；亲子线同色系宽 1.8；兄弟姐妹线 `stroke-dasharray` 虚线；线中点 `<text>` 关系标签，白底圆角 `<rect>` 衬底、竖排或横排小字（11px）

#### 3. 自研力导向布局（约 120-150 行，`requestAnimationFrame` 驱动）

- 每 tick 三种力叠加：
  - **斥力**：节点两两库仑斥力（强度随距离衰减），间距下限 40px
  - **弹簧引力**：每条 link 按目标长度拉近（夫妻目标短 ~70px、亲子 ~110px、兄弟姐妹 ~130px）
  - **向心力**：轻微拉回画布中心防飞散；`gen` 不同的节点加弱垂直分层力，使家族代际大致分层又保持力导向有机感
- alpha 从 1 衰减至 ~0.01 阈值后停止仿真；节点被拖拽时临时 pin 坐标
- 初始坐标：按 `gen` 分层预置 y，同代横向错开，收敛更快

#### 4. 交互（Pointer Events 统一鼠标/触摸）

- **单指/鼠标拖拽空白**：平移画布（更新 viewBox 的 x/y）
- **双指捏合**：以双指中点为锚点缩放 viewBox（scale 限制 0.4x–3x）
- **拖拽节点**：pin 住节点跟随手指，松手恢复仿真
- **单击节点**：底部上滑详情卡（头像、姓名、称谓、世代、关系列表如"配偶：林淑芬 / 子女：陈志远、陈志玲"），点击遮罩或空白关闭
- **重置视图按钮**：动画过渡回初始 viewBox 并重播布局
- **节点高亮**：tap/hover 时该节点描边加粗，其关联节点与连线高亮，其余元素降透明度

#### 5. UI 与手机适配

- 顶部工具栏：`position: fixed` 半透明毛玻璃（`backdrop-filter: blur`），左侧标题"家族图谱"，右侧重置按钮（SVG 图标，触控区 ≥44px）
- 详情卡：底部 `border-radius: 16px 16px 0 0` 上滑卡片 + 半透明遮罩
- `<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1, user-scalable=no">`；`touch-action: none` 防浏览器手势冲突；`user-select: none`
- 竖屏优先，文字随 viewBox 等比缩放保持清晰

## Assumptions & Decisions

1. 零依赖是硬约束：不引 CDN、不用外部图片字体，头像用程序化 SVG 生成。
2. 示例数据为虚构中文家族（三代 12-14 人），集中定义在 JS 顶部，用户可自行替换。
3. 关系类型收敛为夫妻/亲子/兄弟姐妹三种，标签直接标在连线上（复刻参考图核心特征）。
4. 自研力导向而非引入 d3/ECharts，保证单文件离线可运行；节点规模小无性能问题。
5. 明确不做（用户选择核心体验）：搜索、按关系筛选、展开/收起、导出图片、统计面板。

## Verification

1. **桌面验证**：浏览器直接打开 `index.html`，力导向约 2-3 秒收敛稳定，节点无重叠、标签可读。
2. **鼠标交互**：拖拽空白平移、滚轮缩放（以光标为锚点）、拖拽节点、单击弹详情卡、重置按钮回初始视图。
3. **移动端验证**：Chrome DevTools 设备模拟（iPhone 12/13 尺寸）——单指拖动平移、双指捏合缩放、轻点节点弹卡均正常，无页面整体滚动/缩放冲突。
4. **视觉对照**：与参考图核对配色（淡紫背景、紫色描边节点、白底关系标签）、节点文字双行结构、tooltip 风格是否还原。
5. **边界**：连续快速双指操作、拖拽节点撞向边缘时不抖动/不飞散。
