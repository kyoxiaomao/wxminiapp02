## 〇、名词解释（先看这个）

| 术语 | 意思 | 类比 |
|---|---|---|
| **集合（Collection）** | 存放一类数据的容器 | 相当于一张 Excel 表 / 数据库的「表」 |
| **文档（Document）** | 集合里的一条记录 | 相当于 Excel 的「一行」 |
| **字段（Field）** | 一条记录里的一个信息项 | 相当于 Excel 的「一列」 |
| **openId** | 微信用户的唯一编号（登录后拿到） | 这条记录「属于谁」的账号锚点 |

本项目要建 **4 个集合**：`cards`（名片）、`graphs`（图谱）、`nodes`（图谱节点）、`edges`（关系连线）。

## 一、cards —— 名片表（核心，一人一张完整信息）

「名片」是全局唯一实体：一个人在小程序里只有一张名片，图谱里只是引用它。

## 二、graphs —— 图谱表（一个图谱 = 一个关系圈）

如「陈氏家族图谱」「公司同事图谱」。图谱本身只是个容器，成员信息存在 nodes 里。

| 字段名 | 类型 | 中文含义 | 示例值 |
|---|---|---|---|
| `id` | 文本 | 图谱唯一编号 | `graph-family` |
| `name` | 文本 | 图谱名称 | `陈氏家族图谱` |
| `type` | 文本 | 图谱类型：`family` 家族 / `company` 公司 / `customer` 客户 / `cars` 车友 / `fish` 钓友 / `custom` 自定义 | `family` |
| `typeLabel` | 文本（可选） | 自定义类型的显示名（如「球友」），type=custom 时才用 | `球友` |
| `coverColor` | 文本 | 封面色（图谱列表卡片的背景色） | `#d9c9dd` |
| `avatar` | 文本（可选） | 图谱头像图片地址，没有则列表显示类型 emoji | `https://...` |
| `createdAt` | 文本 | 创建时间 | `2026-01-20 10:00:00` |
| `openId` | 文本（新增） | **归属账号**：这个图谱属于哪个微信用户 | `oXy7...` |

## 三、nodes —— 图谱节点表（图谱里的「一个人」）

图谱画布上的每个圆圈=一个节点。**节点不存人物信息，只存引用**（指向 cards 里的名片）+ 图谱内的显示信息。

| 字段名 | 类型 | 中文含义 | 示例值 |
|---|---|---|---|
| `id` | 文本 | 节点唯一编号 | `node-g1` |
| `graphId` | 文本 | 属于哪个图谱（对应 graphs.id） | `graph-family` |
| `cardId` | 文本（可为空） | **关联的名片**（对应 cards.id）。空 = 匿名节点（还没关联名片的占位圆圈） | `card-g1` |
| `nickname` | 文本 | 图谱内显示昵称（如「三叔」，和名片上的姓名是分开的，各图谱可不同） | `陈明` |
| `role` | 文本 | 称谓/角色（如 奶奶、长媳、上级） | `长孙` |
| `gen` | 数字（可选） | 代际（家族图谱分层布局用，1=第一代，长辈朝上晚辈朝下） | `2` |

---

## 四、edges —— 关系连线表（两个人之间的一条线）

图谱里节点与节点之间的连线，带关系标签。

| 字段名 | 类型 | 中文含义 | 示例值 |
|---|---|---|---|
| `id` | 文本 | 连线唯一编号 | `edge-1` |
| `graphId` | 文本 | 属于哪个图谱（对应 graphs.id） | `graph-family` |
| `source` | 文本 | 起点节点 id（对应 nodes.id） | `node-g1` |
| `target` | 文本 | 终点节点 id（对应 nodes.id） | `node-g0` |
| `type` | 文本 | 关系类型（决定连线样式）：`spouse` 夫妻 / `parent` 亲子 / `colleague` 同事 / `friend` 朋友 / `custom` 自定义 | `parent` |
| `label` | 文本 | 关系标签文字（线上显示的字） | `长子` |

## 五、四个集合怎么串起来（一张图看懂）

```
graphs（图谱）
   │  1 个图谱
   ├── nodes（节点）──cardId──► cards（名片）◄──openId── 归属账号
   │      │  1 个节点=1 个人（圆圈）
   └── edges（连线）──source/target──► nodes
          │  1 条连线=两个人的关系
```

- 同一张 **名片**（cards）可以被多个图谱的节点引用（如家族图谱、公司图谱里都有你）
- 改名片信息 → 所有引用它的节点显示都跟着变（「名片全局唯一」原则）
- 图谱内昵称/称谓存在节点上，改了不影响名片本身
