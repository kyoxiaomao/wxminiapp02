## 〇、要求和决定

### 0.1 为什么做

用名片最多的是企业。员工发名片，除了个人联系方式，企业也希望顺带介绍公司、产品和案例。现在名片上只有一行「公司」文字，企业想展示的东西放不下。

做法是在个人名片里放一个「企业主页」入口，点了进入单独的企业主页。企业主页和活名片是同一个思路：企业信息改一处，所有拿到名片的人看到的都是最新的。以后企业版的付费和认证，也落在企业主页上。

### 0.2 用户定的（2026-11-10）

1. 个人名片里放一个**企业主页按钮**，点了跳到一个**单独的企业主页页面**。
2. 企业主页**在手机上编辑**。
3. 以后商业化：**企业版付费 + 认证**。本轮不做，只预留字段。

### 0.3 我定的默认做法，等确认

4. **本轮只做「一个人建、绑定自己的名片」**。邀请同事加入、团队成员模块放到下一版（V1.2.2）。
5. 每个用户**只能管理 1 个企业主页**，名片只能绑定自己管理的企业主页。
6. **模块**：封面（必填名称和 Logo）、企业简介、产品与服务、案例与资质、联系我们。顺序固定，没填内容的模块在查看页不显示。
7. **数量上限**：产品最多 20 个；每个模块的图片最多 9 张。
8. **内容安全**：保存走云函数，文字和图片都过微信的内容安全检测，不通过就拒绝保存，并提示是哪一块有问题。
9. **未认证标记**：查看页名称旁边显示灰色小字「未认证」；数据里预留 `certified`（是否认证）和 `plan`（免费版 / 企业版）两个字段，本轮固定为未认证、免费版。
10. **按钮位置**：名片详情页「公司」「职位」那两行下面，单独一条：企业 Logo + 企业名称 + 「企业主页 ›」。
    - 绑定了企业主页：所有人都能看到这一条（包括收到活名片的人）；
    - 没绑定：只有名片本人在编辑态看到「＋ 创建企业主页」，别人看不到任何东西。
11. **企业名称和名片「公司」字段各管各的**：创建企业主页时，名称默认填名片上的「公司」，之后两边分别修改，不互相同步。
12. **编辑页整体保存**：改完点「保存」一次提交（每次保存都要过内容检测），不像名片详情那样输入即保存。离开时有未保存的修改，提示「放弃修改？」。
13. **企业主页能单独分享**。从名片进入，或者打开别人分享的企业主页时，页面底部有一条「名片主人」（头像、姓名、职位、拨打、看名片），让看企业的人能找回这个人。分享企业主页时，和分享名片一样，把分享人的名片设为公开。
14. **可以删除企业主页**：删除前确认；删除后，自己名片上的绑定一起解除。

### 0.4 不做（本轮）

- 邀请同事、团队成员模块（V1.2.2）
- 付费、认证、访客统计、留言咨询（以后的企业版）
- 用 `web-view` 嵌企业现有的官网（每个网站域名都要在小程序后台登记、并在对方网站放校验文件，做不到；官网地址只做「复制链接」）
- 招聘、优惠活动等其他模块；模板、AI 一键生成
- 公司图谱挂到企业主页上
- 给名片现有内容补做内容安全检测

### 0.5 以后企业版的方向（只是方向，本轮不定）

| | 免费版（本轮） | 企业版（以后，付费） |
|---|---|---|
| 认证 | 显示「未认证」 | 认证标识 |
| 团队成员 | 只有自己 | 邀请同事，人数按档位 |
| 产品数量 | 最多 20 个 | 更多 |
| 访客统计 | 无 | 多少人看过、看了哪些产品 |
| 留言咨询 | 无 | 有 |

## 一、改哪些地方

| 地方 | 做什么 |
|---|---|
| 新集合 `companies` | 企业主页数据（字段见 1.1）。权限：**所有用户可读，客户端不能写**，只由云函数 `saveCompany` 写入 |
| 新云函数 `cloudfunctions/saveCompany/` | 新建、修改、删除企业主页：校验调用者是管理员；文字、图片过内容安全检测；新建时把自己名片的 `companyId` 设上，删除时解除；`updatedAt` 刷新 |
| `cloudbaserc.json` | 登记 `saveCompany` |
| `src/types/index.ts` | 新增 `Company` 类型；`Card` 加可选字段 `companyId` |
| `src/services/company.ts`（新） | 读企业主页（按 id）、读我管理的企业主页、调 `saveCompany` |
| `src/store/index.ts` | 企业主页按 id 缓存；`applySharedContent` 加上 `companyId`，让活名片的持有人也能拿到企业主页 |
| `src/pages/company/index`（新） | 企业主页查看页（布局见 1.2），带分享 |
| `src/pages/company/edit/index`（新） | 企业主页编辑页（见 1.3） |
| `src/app.config.ts` | 登记两个新页面；如果主包超过 2MB，就把这两个页面放进分包；加 `requiredPrivateInfos: ["chooseLocation"]`（编辑页选地址要用） |
| `src/pages/card/detail/index.tsx` + `.module.scss` | 企业主页入口条 / 「＋ 创建企业主页」（见第 10 条） |
| 微信公众平台（后台操作，不改代码） | 「用户隐私保护指引」加上「选择位置」（编辑页选企业地址用） |

### 1.1 `companies` 字段

| 字段 | 说明 |
|---|---|
| `id` | 企业主页 id |
| `adminOpenId` | 管理员（建它的人） |
| `name` / `logo` / `slogan` / `cover` | 名称、Logo、一句话介绍、封面图 |
| `intro` | 企业简介：`{ text, images[] }` |
| `products` | 产品与服务：`[{ id, name, desc, price?, image }]`，最多 20 个 |
| `cases` | 案例与资质：`{ text?, images[] }` |
| `contact` | 联系我们：`{ phone?, email?, website?, address?, lat?, lng? }` |
| `certified` / `plan` | 预留：本轮固定 `false` / `'free'` |
| `createdAt` / `updatedAt` | 时间 |

### 1.2 查看页布局（从上到下）

1. **封面**：封面大图，上面压着 Logo、企业名称、「未认证」小字、一句话介绍。
2. **企业简介**：一段文字和几张图，点图大图预览。
3. **产品与服务**：两列卡片（图片、名称、价格），点了弹出详情（大图、介绍）。
4. **案例与资质**：图片宫格，点了大图预览。
5. **联系我们**：电话（拨打）、邮箱（复制）、官网地址（复制）、地址（小地图显示位置，点「导航」打开微信地图）。
6. **底部「名片主人」条**（第 13 条）。
7. 右上角：管理员看到「编辑」；所有人都能分享。

### 1.3 编辑页（手机上）

- 和查看页同样的顺序，一块一块地编辑。
- 图片：从相册选或拍照，压缩后传云存储（`companies/<企业主页 id>/…`），可以删除。
- 产品：添加、编辑、删除、上移、下移。
- 地址：点了打开微信的选位置，选好后带回地址文字和经纬度。
- 底部「保存」：整体提交，检测不通过时停在编辑页并标出是哪一块；最底下有「删除企业主页」（红色，二次确认）。

## 二、分几步、每步怎么查

1. **数据和云函数**：建 `companies` 集合并设权限；写 `saveCompany`，部署。
   **查**：在云开发控制台调用测试，确认：新建成功；别人的 openid 改不了；包含违规文字的内容被拒；客户端直接写 `companies` 被权限挡住。
   **开发前要查**：图片检测用同步还是异步接口（`security.imgSecCheck` 或 `security.mediaCheckAsync`），按微信当前文档定。要求不变：检测不通过的图片不能出现在查看页。
2. **类型、数据入口、store**：`Company` 类型、`services/company.ts`、`applySharedContent` 加 `companyId`。
   **查**：`npm run build:weapp` 不报错。
3. **编辑页**：新建 → 填各模块 → 保存 → 再进来修改 → 删除。
   **查**：开发者工具里走通；云数据库里的数据和填的一致。
4. **查看页 + 分享**：各模块显示、没填的模块不显示、名片主人条、分享。
   **查**：用第二个微信号打开分享出去的企业主页，能看到内容和名片主人条。
5. **名片入口**：详情页入口条、「＋ 创建企业主页」。
   **查**：本人编辑态、本人预览、收到活名片的人，三种情况显示都对。
6. **真机**：安卓、苹果各走一遍第三节的验收清单，再提交微信审核。

## 三、怎么验（真机）

**创建和编辑**
- [ ] 我的名片（编辑态）在公司、职位下面看到「＋ 创建企业主页」；点「预览」后看不到
- [ ] 创建时企业名称默认是名片上的「公司」；Logo 和名称没填时不能保存
- [ ] 各模块都能填：封面、简介和图片、产品（加、改、删、排序）、案例图片、电话、邮箱、官网、地址（选位置）
- [ ] 产品加到第 20 个之后不能再加；每个模块的图片加到第 9 张之后不能再加
- [ ] 有未保存的修改时点返回，提示「放弃修改？」
- [ ] 填一段明显违规的文字保存，被拒绝，并提示是哪一块
- [ ] 保存后重进，内容都在
- [ ] 已经有企业主页的人，不能再建第二个

**查看**
- [ ] 名片上出现企业 Logo + 名称 + 「企业主页 ›」，点了进入查看页
- [ ] 查看页顺序对；没填的模块不显示；名称旁有「未认证」
- [ ] 产品点开有详情；图片能大图预览；电话能拨；邮箱、官网能复制；地址能导航
- [ ] 管理员右上角有「编辑」，别人没有

**活名片和分享**
- [ ] 把名片分享给另一个微信号，对方的名片上也有企业主页入口，点进去内容一致
- [ ] 管理员改了企业主页，对方再进企业主页看到的是新内容
- [ ] 从企业主页右上角分享给另一个微信号，对方打开后底部有「名片主人」条，能拨打、能看名片
- [ ] 没绑定企业主页的名片，别人看不到任何企业主页入口

**删除**
- [ ] 删除企业主页要二次确认；删完名片上的入口消失，「＋ 创建企业主页」重新出现
- [ ] 之前分享出去的企业主页链接，打开显示「企业主页已删除」，不报错、不白屏
