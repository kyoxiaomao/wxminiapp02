## 一、项目简介

**名片图谱**是一个微信小程序，用「图谱」组织身边的人和关系，名片永远是最新的。

- **一句话**：一张名片，一份图谱，让关系永远是最新的。
- **解决什么问题**：
  - 纸质名片、群里换的名片，发完就过时，对方换了电话没人知道；
  - 家人的电话、生日、称谓散落在各处，长辈和晚辈的关系，小孩子更是记不清；
  - 同一个人在不同圈子里的身份不同（家里是「弟弟」，公司是「实习生」），通讯录表达不了。
- **怎么解决**：
  - **活名片**：分享名片只是给对方一个引用，不复制内容。源名片一改，所有收下它的人看到的都是最新的，还会出现「有更新」红点；对方第一次收下时，自动把对方的名片回赠回来，一次分享就完成互换。
  - **关系图谱**：把人和关系画成可以拖、可以缩放的图。家族、公司、客户、车友、钓友、自定义 6 种图谱，同一张名片在不同图谱里有不同称谓。
- **用户与场景**：家庭（家族图谱，几代人一图看清）、公司（同事关系）、社团和客户圈（自定义图谱）。
- **上线情况**：微信小程序已上线；主体是杭州极星智能科技有限公司，备案号 浙ICP备2025175380号-2X。
- **团队**：爸爸带姐姐、弟弟，一家人和 AI（TRAE）结对开发。

## 三、架构与目录

### 3.1 整体架构

```
┌──────────────── 微信小程序（Taro + React） ────────────────┐
│ 页面：图谱 / 名片 / 我的（3 个 Tab）+ 名片详情、编辑、首登、反馈、关于 │
│        │ 读写                                               │
│ Store（内存数据 + 版本号通知页面重绘）                         │
│   · 写穿透：先改内存马上生效，再异步写云端，失败直接报错          │
│   · 教程沙箱：新人指引期间只改内存，不写云端                     │
└────────┬──────────────────────┬─────────────────────────┘
         │ 客户端 SDK（按 openid 隔离）│ 调云函数（管理员身份）
┌────────▼──────────────────────▼─────────────────────────┐
│ CloudBase：云数据库（cards/graphs/nodes/edges/users/feedback）│
│            云函数（login / getCard / getPhoneNumber …）       │
│            云存储（头像、照片、图谱头像）                       │
└─────────────────────────────────────────────────────────┘
```

**关键机制**

- **活名片**：收到的名片在自己的 `cards` 里存一条引用（`source='shared'`、`refCardId=源名片 id`）。打开时通过 `getCard` 拉源名片最新内容；源名片每改一次 `contentVersion` 加一，`updatedVersion > seenVersion` 就显示红点。
- **只放行分享过的名片**：`getCard` 只返回 `shared=true` 的源名片，没分享过的名片别人读不到。
- **互换**：第一次收下时 `getCard` 带 `swap: true`，把收下人的名片回赠给分享人；做了去重，重复打开不会收出多张。
- **称谓归图谱**：称谓存在图谱节点（`nodes.role`）上，不存在名片上，所以每个图谱可以各叫各的。

### 3.3 数据集合

| 集合 | 存什么 | 谁能读写 |
|---|---|---|
| `cards` | 名片：自己建的（`source='manual'`）和收到的活名片引用（`source='shared'`） | 本人；分享过的源名片经 `getCard` 给别人读 |
| `graphs` | 图谱：名称、类型、封面色、头像 | 本人 |
| `nodes` | 图谱里的人：所属图谱、关联名片（可为空）、称谓、辈分、坐标 | 本人 |
| `edges` | 两人之间的关系：起点、终点、关系类型、标签 | 本人 |
| `users` | 账号：openid、是否完成首登、是否看过指引、登录次数 | 云函数 / 本人 |
| `feedback` | 意见反馈 | 本人写入 |
| `demo_*` | 审核用演示账号的共享数据 | 云函数 `demoRW` |

### 3.4 云函数

| 云函数 | 作用 |
|---|---|
| `login` | 返回 openid，首次登录建 `users` 记录、累计登录次数 |
| `getPhoneNumber` | 用授权 code 换真实手机号（企业主体能力） |
| `getCard` | 读分享过的源名片；`swap=true` 时把收下人的名片回赠给分享人 |
| `accountLogin` / `demoRW` | 平台审核用的账号密码登录和演示数据读写（界面入口已隐藏） |
| `seed` / `migrateDemo` | 演示数据的初始化和迁移工具 |
