# V1.1 功能更新：新人指引（可重复学习）

- 版本：V1.1
- 日期：2026-10-21
- 状态：待开发
- 涉及模块：图谱页、名片页、store、mock 数据、教程状态机

## 目标

为首次进入图谱页的新用户提供一次可跳过的新人指引，并保留左上角问号入口，支持随时重复学习以下核心操作：

- 图谱节点长按添加 / 删除
- 节点绑定名片
- 修改节点之间的关系

指引使用一份家族图谱 mock 数据演示，结束后自动清除，不影响用户真实数据。

---

## 关键设计决策

1. **Mock 数据只进内存沙箱，绝不写入云端集合。** 新增 `tutorialCards / tutorialNodes / tutorialEdges / tutorialGraphs` 四组内存数组，加载时从 `src/mock/family.ts` 读取家族数据，清理时直接清空数组。这样“切走、退出、杀进程”都不会留下痕迹，也不需要云端清理任务。
2. **Mock 实体 id 全部重映射。** `family.ts` 里是固定 id（`card-p1`、`graph-family`），直接使用会与真实数据/云唯一索引冲突。加载时统一加 `tut-<batch>-` 前缀，并建立 `code → id` 映射；步骤 JSON 一律用 `code` 引用，不写死 id。
3. **只持久化步骤快照，不持久化 mock 数据。** 中断后点问号重新加载 mock，并按快照重建练习节点、关系和绑卡状态。

## 一、数据层：store 增加教程沙箱

- [ ] 在 `src/store/index.ts` 增加教程模式字段：`tutorialActive`、`tutorialBatchId`、四组内存数组、`tutorialEgoNodeId`、`prevGraphId`。
- [ ] 新增 `loadTutorialFamily()`：只导入家族 `familyGraph / familyCards / familyNodes / familyEdges`，不导入公司图谱；深拷贝后重映射 id，并把“我”节点设为教程 ego、所有节点固定坐标/冻结物理。
- [ ] 新增 `clearTutorialData()`：清空数组、复位模式、`emit()`，**不调用任何 `dbRemove`**。
- [ ] 写操作分流：教程期间 `createNode / updateNode / deleteNode / createEdge / updateEdge / deleteEdge / createGraph / deleteGraph / createCard / updateCard / deleteCard / saveNodeLayout` 全部只改内存数组，禁止走 `pushToCloud`。
- [ ] 读操作合并：`listGraphs / listNodes / listEdges / getCard / getNode / getEdge / getCardOfNode` 在教程期间包含沙箱数据。
- [ ] `getMyCard()` 必须排除教程卡片，避免 mock 里的“我”（`isMe: true`）顶掉用户真实名片。
- [ ] 教程节点布局不落云端；清理时先切回 `prevGraphId` 再 `emit`，并加 `suppressSync` 标志，避免图谱页的“当前图谱被删除”兜底逻辑误切图谱。

**验收**：加载前后真实图谱/名片数量与 id 完全一致；断网可完整跑完教程；清理后 store 快照与加载前一致。

## 二、步骤 JSON 与状态机

- [ ] 新增 `src/tutorial/family-guide.json`，作为唯一文案/流程来源。
- [ ] 步骤字段：`id`、`title`、`desc`、`target`（`kind` + `code`/`edgeRef` + `padding`）、`camera`（聚焦 code、缩放）、`advance`（`longPress / nodeAdded / detailOpened / linkPending / cardBound / edgeChanged / nodeDeleted / manual`）、`hint`、`allowPrev`。
- [ ] 步骤序列：
  1. 欢迎（全屏遮罩 + 开始）
  2. 长按「我」（聚焦 `g1`，判定长按事件）
  3. 点 ＋（判定新增节点，记录 `practiceNodeId`）
  4. 点开新成员（判定详情卡打开）
  5. 点「关联名片」（判定 `linkPendingNodeId` 写入并跳到名片页）
  6. 名片页选一张并点关联（判定 `practiceNode.cardId` 有值）
  7. 点关系标签改名（判定该边 `label` 变化）
  8. 长按新节点 → 点 － → 确认删除（判定节点消失）
  9. 完成面板（点完成才清理）
- [ ] 新增 `src/tutorial/controller.ts`：`start / next / prev / skip / exit / complete / notify(event)`，并持久化 `{ stepIndex, practiceNode, edgeRef, cardRef, prevGraphId }` 到 `Taro.setStorage`。
- [ ] **只持久化步骤快照，不持久化 mock 数据**。恢复时重新 load 并按快照重建练习节点、边、绑卡状态。
- [ ] 定义续播降级规则：中断在“名片页”步骤时恢复到“点关联名片”这一步；中断在确认弹窗时恢复到上一步，避免恢复后自动跨页。

**验收**：在第 2~8 步任意位置切走/杀进程，点问号都能恢复到对应步骤，且 mock 数据无残留。

## 五、生命周期与清理规则

- [ ] 图谱页 `useDidHide`：教程进行中且不是“去名片页关联”这一预期跳转 → 保存快照、清空 mock。
- [ ] 名片页 `useDidHide`：处于教程关联阶段但未完成关联 → 视为中断，清空 mock。
- [ ] 图谱页 `useDidShow`：从名片页返回时校验 `practiceNode.cardId`，成功则推进，失败则停在原步骤并提示重新选择。
- [ ] 完成、跳过、退出、切 tab、杀进程五条路径统一走 `clearTutorialData()`。
- [ ] 退出/跳过时保留步骤快照；完成时清空快照。
- [ ] 清理后恢复用户原图谱并重新取景，不要停留在已删除的教程图谱上。
- [ ] 重复点 `?` 先清空旧沙箱再加载，保证幂等。
